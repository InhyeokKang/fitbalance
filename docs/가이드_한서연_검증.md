# 한서연 가이드

읽는 데 5분. 이 문서 하나로 시작할 수 있게 썼습니다. 모르는 게 나오면 강인혁에게 물어보세요.

---

## 1. 우리가 만든 게 뭔가요

**직장인이 자기 몸 어디가 약한지 재고, 퇴근길에 다닐 수 있는 공공 체육 강좌를 받는 앱**입니다.
이름은 **fitbalance**입니다.

왜 만들었냐면, 운동을 해야 한다는 건 다 아는데 두 가지에서 막히기 때문입니다.

1. 뭘 해야 할지 모른다 — 그냥 헬스장 가서 아무거나 한다
2. 퇴근하면 갈 데를 찾을 기운이 없다 — 검색하다 포기한다

그래서 앱이 이렇게 흘러갑니다.

```
집에서 3가지 측정  →  또래 100명 중 몇 등인지 확인  →  약한 곳에 맞는
(줄자·초시계)         (국민체력100 기준표와 대조)      퇴근길 강좌·시설 추천
```

**공모전 출품작**이라 "공공데이터를 실제로 썼는가"가 중요합니다. 그래서

- 체력 기준표: 국민체육진흥공단 **국민체력100** 측정 기록 15만 건에서 뽑았습니다
- 시설·주소·좌표: 공공데이터포털 **공공체육시설** 34,727곳에서 가져왔습니다
- 체력인증센터: 전국 78개소 실제 목록입니다

지어낸 데이터가 아니라는 게 이 앱의 핵심입니다. 그래서 **검증이 중요합니다.**

## 3. 앱 켜기 (제일 먼저)

### 3-1. 내려받기

**https://inhyeokkang.github.io/fitbalance/**

쓰는 컴퓨터에 맞는 걸 누르세요.

| 컴퓨터 | 누를 버튼 | 받은 뒤 |
| --- | --- | --- |
| 윈도우 | **Windows용 받기** | 압축 풀고 `설치.bat` 더블클릭 |
| 맥 | **macOS용 받기** | 압축 풀고 `설치.command` 더블클릭 |

**안드로이드 폰이 있다면** `APK 받기`가 훨씬 빠릅니다. 폰에 옮겨 설치한 뒤,
앱 안에서 톱니바퀴 → 서버 주소에 강인혁이 알려주는 주소를 넣으면 됩니다.

### 3-2. 처음 실행하면

- **약 2GB를 내려받습니다. 10~20분 걸립니다.** 안드로이드 에뮬레이터(= 컴퓨터 안의 가짜 폰)를
  까는 과정입니다. 처음 한 번만 그렇고, 다음부터는 켜기만 합니다.
- 검은 창이 여러 번 뜹니다. 정상입니다. **닫지 마세요.**
- 끝나면 가짜 폰이 화면에 뜨고 앱이 저절로 열립니다.

### 3-3. 막히면

| 증상 | 어떻게 |
| --- | --- |
| 윈도우: "Windows의 PC 보호" 파란 창 | **추가 정보** → **실행** |
| 맥: "확인되지 않은 개발자" | 파일에 **오른쪽 클릭 → 열기** → 열기 |
| "파이썬이 없습니다" 라고 나옴 | https://www.python.org/downloads/ 에서 설치 후 다시 실행 |
| 앱에 "서버 연결을 확인해 주세요" | 검은 창이 닫혔는지 확인. 설치 파일을 다시 실행하면 서버가 다시 켜집니다 |
| 한글이 안 쳐짐 | 입력창을 누르고 자판 아래 **지구본 키**를 누르면 한글로 바뀝니다 |

> **중요**: 이 앱은 검은 창(서버)이 켜져 있어야 동작합니다. 창을 닫으면
> 진단·추천·검색이 전부 멈춥니다. 앱만 켜져 있고 서버가 꺼져 있으면 오류가 납니다.

## 4. 앱 한 바퀴 돌아보기

처음 켜면 **직장과 집을 물어봅니다.** 실제로 다니는 곳으로 넣으세요
(예: 직장 `중구 회현동`, 집 `서초구 반포동`). 동 이름으로 검색하면 나옵니다.

그다음 홈에서 이렇게 갑니다.

1. **집에서 재고 시작하기** → 나이·키·몸무게 + 3가지 측정값 입력
   - 실제로 재보는 게 가장 좋지만, 급하면 **예시값으로 둘러보기** 버튼이 있습니다
2. **진단하기** → 점수, 불균형 유형, 체력요인별 순위가 나옵니다
3. **이 약점에 맞는 강좌 보기** → 퇴근 동선 안의 강좌 목록
4. 강좌를 누르면 상세, **지도로 보기**를 누르면 지도

그 밖에 볼 것

- 홈 아래 **가까운 체력인증센터 찾기** — 전국 78개소, 첫 방문 준비 안내
- 홈 오른쪽 위 **톱니바퀴** — 직장·집·퇴근 시각·거리 바꾸기
- 홈의 **잴 여건이 안 돼요 · 6문항 자가진단** — 도구 없이 하는 버전

## 5. 무엇을 봐야 하나요

"이상한 것"이 막연하니, 아래 다섯 가지를 기준으로 보세요.

### (1) 말이 안 되는 결과

- 측정값을 아주 좋게 넣었는데 "미흡"이 나오는가
- 아주 나쁘게 넣었는데 "우수"가 나오는가
- 남성/여성을 바꿨는데 순위가 그대로인가 (그러면 이상합니다)
- 나이를 25세 → 55세로 바꿨는데 순위가 안 변하는가

### (2) 추천이 납득되는가

- 약점이 **근지구력**인데 추천 1위가 그와 상관없는 종목인가
- 퇴근 시각을 19:00으로 했는데 **19:00보다 이른** 강좌가 나오는가
- "동선에서 1.2km"라는데 지도로 보면 전혀 딴 데인가
- 거리를 1km로 줄였는데 결과가 그대로인가

### (3) 화면이 깨지거나 멈추는가

- 글자가 잘리거나 버튼이 화면 밖으로 나가는가
- 뒤로 가기를 눌렀을 때 엉뚱한 화면으로 가는가
- 로딩이 10초 넘게 안 끝나는가
- 앱이 갑자기 꺼지는가

### (4) 문구가 어색한가

- 무슨 말인지 모르겠는 안내 문구
- 오타, 띄어쓰기
- 처음 보는 사람이 이해 못 할 용어

### (5) 지방에서도 되는가

톱니바퀴에서 직장·집을 **부산·대구·제주** 등으로 바꿔 보세요.
서울에서만 되고 지방에서 안 되면 큰 문제입니다.

## 6. 진단 결과 확인 (8/19)

이건 조금 다른 일입니다. **앱이 내놓은 순위가 진짜 맞는지** 대조하는 작업입니다.

강인혁이 `data/norms.csv`(체력 기준표)를 줍니다. 엑셀로 열 수 있습니다.

```
gender, age_band, item, percentile, value
M, 30-34, sit_up, 50, 41.0      ← 남성 30~34세 교차윗몸일으키기 50백분위 = 41회
```

**방법**

1. 앱에 값을 넣고 나온 순위를 적는다 (예: 남성 32세, 교차윗몸일으키기 38회 → 69등)
2. 기준표에서 `M / 30-34 / sit_up` 줄들을 찾는다
3. 38회가 몇 백분위쯤인지 눈으로 확인한다
4. **앱 순위 = 100 − 백분위** 가 맞는지 본다 (69등이면 백분위 31)
5. 어긋나면 리포트에 적는다

10건만 하면 됩니다. 남녀·나이대를 섞어서 고르세요.

> 딱 맞아떨어지지 않아도 됩니다. 백분위 사이는 계산으로 메우기 때문에
> **1~2 차이는 정상**입니다. 10 이상 차이나면 적어 주세요.

## 7. 리포트 쓰는 법

두 가지를 씁니다. 폴더는 `docs/리포트/한서연/` 입니다.

| 무엇 | 언제 | 파일 |
| --- | --- | --- |
| **일지** | 매일 | `2026-08-18.md` 처럼 날짜 파일. 미리 만들어 뒀습니다 |
| **종합** | 마지막에 한 번 | `종합_검증결과.md` — 진단 대조표·지역별 확인·시연 시나리오 |

날짜 파일을 열어 그날 찾은 것을 적으면 됩니다.
자세한 것은 [docs/리포트/한서연/README.md](리포트/한서연/README.md) 를 보세요.

한 건당 이 다섯 줄이면 충분합니다.

```
### [높음] 부산으로 바꾸면 강좌가 안 나옴
- 언제: 8/18 14:20
- 어떻게 하면: 톱니바퀴 → 직장 부산 서면, 집 부산 해운대 → 저장 → 강좌 보기
- 나온 것: "조건에 맞는 강좌가 없습니다"
- 나와야 할 것: 부산 강좌 몇 개
```

**중요도는 세 단계**로만 나눕니다.

| | 뜻 |
| --- | --- |
| 높음 | 앱이 꺼지거나, 결과가 틀렸거나, 시연 때 보여줄 화면이 안 됨 |
| 보통 | 불편하지만 넘어갈 수 있음 |
| 낮음 | 오타, 문구, 색 |

**"어떻게 하면"을 꼭 적어 주세요.** 강인혁이 똑같이 따라 해서 재현해야 고칠 수 있습니다.
이게 없으면 못 고칩니다.
