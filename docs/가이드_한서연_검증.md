# 한서연 — 검증 트랙 가이드

담당: 매일 나오는 빌드를 직접 써보고, 이상한 걸 찾아 리포트로 남기는 일.
개발자가 못 보는 것을 대신 봐 주는 자리입니다. 코드는 볼 필요 없습니다.

---

## 1. 준비 (처음 한 번만)

### 방법 A — 폰에 앱 설치 (기본)

매일 저녁 단톡에 `app-debug.apk` 파일이 올라옵니다.

1. 파일을 눌러 설치합니다.
2. "출처를 알 수 없는 앱" 경고가 뜨면 허용해 주세요. 정식 스토어 배포 전이라 정상입니다.
3. 이전 버전 위에 그대로 덮어 설치됩니다. 지울 필요 없습니다.

### 방법 B — 컴퓨터에서 브라우저로 보기 (보조)

폰이 여의치 않거나, 같은 화면을 크게 보며 리포트를 쓸 때 씁니다.

1. 강인혁이 보낸 `fitbalance` 폴더를 받습니다.
2. 폴더 안에서
   - 윈도우: **실행_윈도우.bat** 더블클릭
   - 맥: **실행_맥.command** 더블클릭
     (처음엔 "확인되지 않은 개발자" 경고 → 파일 **우클릭 → 열기** 를 고르면 됩니다)
3. 검은 창이 뜨고 잠시 뒤 브라우저가 자동으로 열립니다. 첫 실행은 1~2분 걸립니다.
4. 끝낼 때는 검은 창을 닫으면 됩니다.

> 브라우저 화면은 앱과 디자인·동작이 같게 맞춰 두었지만 **앱이 기준**입니다.
> 둘이 다르게 보이면 그 자체가 리포트 감입니다.

## 2. 매일 할 일 (20~30분)

### 순서

1. 새 빌드를 설치한다
2. 아래 **기본 시나리오**를 처음부터 끝까지 한 번 따라 해 본다
3. 이상한 걸 발견하면 그 자리에서 스크린샷을 찍는다
4. 리포트 시트에 적는다
5. 23시까지 제출. `막힘`은 발견 즉시 단톡에 태그

### 기본 시나리오 (매일 동일하게)

| # | 할 것 | 정상이라면 |
| --- | --- | --- |
| 1 | 앱을 연다 | 홈 화면. 캐릭터가 아령을 들고 있음 |
| 2 | "체력 측정 시작하기" | 입력 화면. 캐릭터가 "8가지만 넣으면..." 이라고 말함 |
| 3 | "예시값 채우기" | 8칸이 자동으로 채워지고 8/8, 캐릭터가 반짝임 |
| 4 | "진단하기" | 잠깐 로딩 후 진단 리포트 |
| 5 | 리포트를 끝까지 내려본다 | 레이더 차트, 요인별 순위, 측정 항목, BMI |
| 6 | "이 약점에 맞는 강좌 보기" | 강좌 목록. 매칭 점수 높은 순 |
| 7 | "지도로 보기" | 지도에 강좌 마커와 퇴근 동선 |
| 8 | 마커를 눌러본다 | 아래 카드가 그 강좌로 바뀜 |
| 9 | 강좌 하나를 눌러 상세로 | 주소·일정·매칭 점수·추천 이유 |
| 10 | 톱니바퀴 → 설정 | 직장·집 위치, 퇴근 시각, 최대 거리 |
| 11 | 위치나 거리를 바꾸고 "저장" | 추천 목록이 그에 맞게 달라짐 |

### 값을 바꿔가며 볼 것

예시값만 넣으면 매번 같은 결과가 나옵니다. 하루에 **2~3번은 직접 값을 바꿔서** 해 보세요.

- 나이를 20대 / 40대 / 50대로 바꿔보기
- 성별을 여성으로 바꿔보기
- 일부러 이상한 값 넣기 (나이 5, 키 500, 악력 -10, 빈칸으로 두기)
  → **앱이 죽지 않고 "범위로 입력해 주세요" 같은 안내가 떠야 정상입니다**
- 설정에서 최대 거리를 0.5km로 줄이기 → 강좌가 없다는 안내 화면이 나와야 함

## 3. 리포트 쓰는 법

`templates/리포트시트_템플릿.xlsx` 를 쓰세요. 최서영님과 같은 시트를 쓰고 **유형** 열로 구분합니다.

### 심각도 기준

| 심각도 | 뜻 | 예 |
| --- | --- | --- |
| **막힘** | 앱이 죽거나 더 진행할 수 없음 | 진단 버튼 눌렀는데 앱 종료, 화면이 계속 로딩 |
| **불편** | 되긴 되는데 이상함 | 뒤로 갔더니 입력값이 사라짐, 버튼이 화면에 가림 |
| **사소** | 오타·정렬·색 | 띄어쓰기 틀림, 글자가 살짝 잘림 |

### 잘 쓴 리포트 vs 아쉬운 리포트

**아쉬움**: "진단이 안 돼요"
→ 무슨 값을 넣었는지, 어디서 멈췄는지 알 수 없어 재현이 안 됩니다.

**좋음**: 재현 절차를 번호로, 입력값을 그대로, 기대와 실제를 나눠서

> 화면/기능: 진단 리포트
> 재현 절차: 1. 여성 선택 2. 나이 52 키 160 몸무게 55 악력 22 윗몸 15 앞굽히기 12 셔틀런 20 외발서기 8 3. 진단하기
> 기대한 것: 진단 리포트 표시
> 실제 벌어진 것: 로딩 화면에서 30초 이상 멈춤, 결과 안 나옴
> 심각도: 막힘

**핵심은 "다시 해봤을 때 똑같이 재현되는가"입니다.** 그것만 되면 고치는 건 빠릅니다.

### 스크린샷

- 폰: 전원 버튼 + 소리 작게 동시에
- 이상한 화면이 보이면 **일단 찍고** 나서 계속 진행하세요. 나중에 재현이 안 되는 경우가 많습니다.
- 시트의 스크린샷 열에는 링크나 파일명을 적으면 됩니다.

## 자주 나오는 질문

**앱이 설치가 안 돼요** → "출처를 알 수 없는 앱" 설정을 허용해야 합니다. 그래도 안 되면 이전 버전을 지우고 다시 설치해 보세요.

**서버 연결 실패라고 떠요** → 앱은 강인혁 PC의 서버에 연결됩니다. 배포 전(8/17 이전)에는 같은 와이파이가 아니면 안 될 수 있습니다. 단톡으로 알려주세요.

**이건 버그인지 원래 그런 건지 모르겠어요** → 적어 주세요. 판단은 제가 합니다. 안 적어서 놓치는 게 더 나쁩니다.

**같은 문제를 어제도 적었는데요** → 고쳐졌다고 했는데 또 나오면 반드시 다시 적어 주세요. 그게 가장 중요한 정보입니다.
