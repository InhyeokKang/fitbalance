# 데이터 확보 절차 (2026-08-15 변경)

기존 계획은 최서영이 국민체력100 원자료를 직접 내려받아 백분위 기준표까지 만드는 것이었다.
그런데 이 데이터는 **파일 다운로드가 아니라 REST API**이고 활용신청·인증키가 필요하다.
API 호출은 개발 쪽에서 하는 편이 훨씬 빠르므로 **역할을 조정한다.**

---

## 바뀐 분담

| 단계 | 전 | 후 |
| --- | --- | --- |
| 활용신청·인증키 발급 | 최서영 | **강인혁** |
| API 호출·원자료 수집 | 최서영 | **강인혁** (`tools/fetch_kspo.py`) |
| 오입력 제외 기준 정하기 | 최서영 | 최서영 (그대로) |
| 백분위 산출 | 최서영 | 최서영 (원자료 파일을 받아서) |
| 판정 검증 | 최서영 | 최서영 (그대로) |
| 강좌 태그표·주소표 | 최서영 | 최서영 (그대로) |

**최서영은 API를 다룰 필요가 없다.** 강인혁이 넘긴 CSV 파일 하나로 시작한다.

---

## 강인혁이 할 일

### 1. 활용신청 (오늘)

https://www.data.go.kr/data/15108938/openapi.do

- 공공데이터포털 회원가입 → **활용신청** (무료, 대개 즉시 승인)
- 활용목적에 공모전 참가를 명시
- 승인되면 마이페이지에서 **일반 인증키(Decoding)** 복사

### 2. 인증키 등록

`local.properties` 에 한 줄 추가한다. 이 파일은 커밋되지 않는다.

```
DATA_GO_KR_KEY=발급받은인증키
```

### 3. 원자료 수집

```bash
python tools/fetch_kspo.py
```

`data/raw/kspo_measurements.csv` 가 만들어진다.

**실행하면 응답 필드 목록이 화면에 찍힌다. 이걸 반드시 확인할 것.**
공단이 컬럼을 여러 번 바꿔 왔기 때문에 실제 필드명이 예상과 다를 수 있다.
특히 **성별 컬럼이 있는지**가 중요하다. 없으면 성별 구분 기준표를 만들 수 없어
진단 로직 자체를 바꿔야 한다. 스크립트가 없으면 경고를 띄운다.

### 4. 최서영에게 전달

- `data/raw/kspo_measurements.csv` 파일
- 화면에 찍힌 **필드 목록**을 함께 (어떤 컬럼이 어떤 측정 항목인지 매칭해야 함)

---

## 최서영이 할 일 (파일을 받은 뒤)

1. 필드 목록을 보고 **어떤 컬럼이 어떤 측정 항목인지** 매칭
   (`templates/오입력_제외기준.md` 의 표에 기록)
2. 오입력 제외 기준을 정하고 적용
3. 성별 × 나이대(5세 단위) × 항목별로 백분위를 산출해
   `templates/체력기준표_템플릿.xlsx` 의 노란색 value 열을 채움
4. CSV UTF-8로 저장해 전달

기준표 템플릿에는 450줄의 조합이 이미 깔려 있으므로 **값만 채우면 된다.**

---

## 우리가 쓰는 측정 항목과 공단 원자료 매칭

원자료의 컬럼명이 확정되면 아래 표를 채운다. (4번 단계에서 최서영이 작성)

| 우리 `item` | 항목 | 단위 | 원자료 컬럼명 |
| --- | --- | --- | --- |
| `grip` | 상대악력 | % | (악력 컬럼 ÷ 체중 컬럼 × 100) |
| `sit_up` | 교차윗몸일으키기 | 회 | |
| `sit_reach` | 앉아윗몸앞으로굽히기 | cm | |
| `shuttle_run` | 20m 왕복오래달리기 | 회 | |
| `standing_jump` | 제자리멀리뛰기 | cm | |

## 체력인증센터 목록은 이미 확보했다

`data/centers.csv` 에 전국 78개소가 들어 있다. 앱의 "체력인증센터 찾기" 화면이 쓴다.

갱신이 필요하면:

```bash
python tools/fetch_centers.py
```

이건 활용신청이 필요 없다. 국민체력100 공식 홈페이지가 쓰는 목록을 그대로 받아온다.

> 좌표(위경도)는 응답에 없어서 거리순 정렬은 하지 않는다.
> 설정한 직장 지역의 시도를 앞에 놓고, 지도 앱 연결로 대신한다.

---

## 강좌 데이터는 어떻게 하나

`courses.csv` 는 전국 통합 데이터셋이 없다. 시설 정보는
[전국공공시설개방정보표준데이터](https://www.data.go.kr/data/15013117/standard.do)에서
시설명·도로명주소·위경도를 받을 수 있지만, **강좌 시간표는 지자체·시설별로 따로 공개**된다.

따라서 이 부분은 최서영이 수도권 위주로 수집한다. 야간(18:30 이후)·주말 강좌 우선.
