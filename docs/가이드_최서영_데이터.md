# 최서영 가이드

읽는 데 5분. 이 문서 하나로 시작할 수 있게 썼습니다. 모르는 게 나오면 강인혁에게 물어보세요.

## 1. 우리가 만든 게 뭔가요

**직장인이 자기 몸 어디가 약한지 재고, 퇴근길에 다닐 수 있는 공공 체육 강좌를 받는 앱**입니다.
이름은 **fitbalance**입니다.

```
집에서 3가지 측정  →  또래 100명 중 몇 등인지 확인  →  약한 곳에 맞는
(줄자·초시계)         (국민체력100 기준표와 대조)      퇴근길 강좌·시설 추천
```

**관광·체육 공공데이터 공모전** 출품작이고, 심사에서 "공공데이터를 실제로, 제대로 썼는가"가
가장 중요합니다. 앱에 나오는 숫자에는 전부 출처가 있어야 합니다.

| 데이터 | 출처 | 규모 | 상태 |
| --- | --- | --- | --- |
| 체력 기준표 | 국민체력100 측정결과 API | 15만 건 → 450행 | ✅ |
| 공공체육시설 | 공공데이터포털 | 전국 34,727곳 | ✅ |
| 지역 색인 | 위 시설 주소에서 생성 | 2,159곳 | ✅ |
| 체력인증센터 | 국민체력100 공식 목록 | 78개소 | ✅ |
| **강좌 시간표** | **전국평생학습강좌표준데이터** | **?** | ⬜ **최서영 담당** |

## 2. 최서영이 할 일 — 한 줄로

**공공 API에서 전국 강좌 데이터를 받아 앱에 넣고, 그 데이터가 믿을 만한지 검증하는 일.**

손으로 옮겨 적는 작업이 아닙니다. 수집·변환은 **도구가 합니다.**
최서영이 하는 건 **도구를 돌리고, 나온 결과가 맞는지 통계적으로 확인하고, 기준을 문서로 남기는 것**입니다.

| 단계 | 누가 | 무엇 |
| --- | --- | --- |
| 1. 수집 | 도구 | `fetch_lessons.py` — API에서 전국 강좌 수집 |
| 2. 변환 | 도구 | `build_courses_from_lessons.py` — 앱 스키마로 변환 |
| 3. **검증** | **최서영** | 표본 검사, 매칭 정확도, 커버리지 분석 |
| 4. **판정 기준 정리** | **최서영** | 종목·태그 규칙이 타당한지 보고 고치기 |
| 5. **문서화** | **최서영** | 방법론과 한계를 리포트로 |

## 3. 어떤 데이터를 쓰나요

**전국평생학습강좌표준데이터** (공공데이터포털)

```
https://www.data.go.kr/data/15013110/standard.do
API: https://api.data.go.kr/openapi/tn_pubr_public_lftm_lrn_lctre_api
```

강좌 시간표를 전국 단위로 주는 공공데이터를 계속 찾다가 이걸 찾았습니다.
평생학습 강좌라 전부가 체육은 아니지만, **운영요일과 교육시작시각이 채워져 있는**
거의 유일한 전국 데이터입니다.

들어 있는 열

```
강좌명 · 운영요일 · 교육시작시각 · 교육종료시각 · 교육장소
교육장도로명주소 · 운영기관명 · 전화번호 · 홈페이지 · 정원 · 수강료
```

**표본으로 확인한 것** (충주시 99건)

- 체육 강좌 비율 **6.1%**
- 핵심 열(강좌명·요일·시각·장소·주소) 채워진 비율 **100%**
- 예: `근력(코어)운동 및 체조교실A반 / 수+금 / 10:00 / 충주시평생학습관`

이게 전국 규모에서도 같은 비율인지 확인하는 게 첫 번째 일입니다.

## 4. 시작하기

### 4-1. 준비

강인혁에게 프로젝트 폴더를 받으세요. 파이썬이 필요합니다
(없으면 https://www.python.org/downloads/ — 설치할 때 **Add to PATH** 체크).

**활용신청**이 하나 필요합니다. 위 링크에서 오른쪽 위 [활용신청] → 자동승인이라 즉시 됩니다.
인증키는 강인혁이 쓰던 것을 그대로 씁니다(계정당 하나라 새로 안 받아도 됩니다).

### 4-2. 수집

```bash
python tools/fetch_lessons.py
```

전국 강좌를 받아 체육 강좌만 골라 `data/raw/lessons.csv` 로 저장합니다.
끝나면 이렇게 찍힙니다.

```
체육 강좌 1,842건 / 전체 30,215건 (6.1%)

핵심 열이 얼마나 채워졌나
  강좌명           100.0%
  운영요일          98.3%
  교육시작시각        97.1%
```

### 4-3. 변환

```bash
python tools/build_courses_from_lessons.py
```

앱이 쓰는 `data/courses.csv` 로 바꿉니다. 이때 도구가 하는 일

1. **요일 쪼개기** — `화+목` → 두 줄 (앱은 한 줄에 한 요일)
2. **종목 판정** — 강좌명에서 요가·수영·배드민턴 등을 찾음
3. **태그 부여** — 종목 → 근력/근지구력/유연성/심폐/순발력
4. **좌표 붙이기** — 도로명주소를 지역 색인(2,159곳)과 맞춰 동 단위 좌표
5. **중복 제거** — 같은 시설·요일·시각·강좌명은 한 번만

제외된 건수와 이유도 함께 찍힙니다.

```
제외된 것
  종목 판정 실패      312
  요일 없음           28
  좌표 못 찾음        95

좌표 정확도: 동까지 맞은 것 1,204 / 시군구까지만 231
```

**이 숫자들이 검증의 출발점입니다.**

## 5. 검증 — 여기가 최서영의 일

도구가 만든 결과를 그대로 믿으면 안 됩니다. 아래 네 가지를 확인해 주세요.

### (1) 표본 검사 — 무작위 30건

`courses.csv` 에서 **무작위로 30줄**을 뽑아, 원본(`lessons.csv`)과 대조합니다.

| 확인할 것 | 어떻게 |
| --- | --- |
| 요일이 맞게 쪼개졌나 | 원본 `운영요일`이 `화+목`이면 두 줄이 되었나 |
| 시각이 맞나 | `교육시작시각` 그대로인가 |
| 종목 판정이 맞나 | "실버 스트레칭 교실"이 `생활체조`로 갔나 (`웨이트`면 오판) |
| 좌표가 맞나 | 주소를 카카오맵에 넣어보고 좌표가 그 근처인가 |

무작위로 뽑는 법 (엑셀): `=RAND()` 열을 추가하고 정렬해서 위 30줄.

**30건 중 몇 건이 맞았는지**를 리포트에 적어 주세요. 이게 데이터 신뢰도의 근거입니다.

### (2) 커버리지 — 지역이 고른가

시도별로 강좌가 몇 개인지 세어 주세요. 엑셀 피벗테이블이면 바로 나옵니다.

- 특정 지자체만 많고 나머지가 0이면, "전국"이라 말하기 어렵습니다
- 비어 있는 시도가 어디인지 적어 주세요 — **이것도 결과입니다**
- 앱은 강좌가 없어도 시설 추천(전국 5,804곳)으로 넘어가니 앱이 멈추진 않습니다

### (3) 종목·태그 판정 규칙 검토

도구의 판정 규칙은 `tools/build_courses_from_lessons.py` 의 `SPORT_RULES` 에 있습니다.
엑셀로 열지 않아도 되고, 메모장으로 열어 읽을 수 있습니다.

```python
("요가|하타|빈야사", "요가", ["flex", "endurance"]),
("배드민턴", "배드민턴", ["cardio", "power"]),
```

**확인할 것**

- 놓친 종목이 있는가 (예: "밸리댄스"가 없으면 판정 실패로 빠집니다)
- 태그가 과한 건 없는가 — 5개를 다 1로 주면 추천이 무의미해집니다
- 애매한 것: "실버 요가"는 유연성만? 근력도?

고쳐야 할 규칙을 리포트에 적어 주시면 강인혁이 반영합니다.
직접 고쳐도 됩니다(줄 하나 추가하면 됩니다).

### (4) 이상치 찾기

- 시작 시각이 `05:00` 이나 `23:00` 인 강좌 — 오타일 수 있습니다
- 같은 시설에 같은 시각 강좌가 10개 넘게 몰린 곳
- 강좌명에 `모집중`, `마감`, `2025년` 처럼 실제 강좌명이 아닌 말이 섞인 것
