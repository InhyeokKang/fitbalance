# 최서영 — 데이터·보고서 트랙 가이드

담당: 앱이 쓰는 데이터를 엑셀로 만들어 넘기고, 앱 판정이 맞는지 대조하고,
제출용 보고서 초안을 쓰는 일. 전부 엑셀·문서 작업이며 코딩은 없습니다.

---

## 0. 가장 중요한 것 한 가지

**열 이름과 순서를 절대 바꾸지 마세요.**

서버가 파일을 읽을 때 열 구성을 먼저 검사합니다. 하나라도 다르면 적재를 거부하고,
그날 빌드가 통째로 멈춥니다. 값이 이상하거나 항목이 부족하면
**스키마를 고치지 말고 강인혁에게 먼저 알려 주세요.**

`templates/` 폴더의 템플릿으로 시작하시면 열 구성이 이미 맞춰져 있습니다.

### 저장 형식

엑셀에서 작업하시고, 넘기실 때만 CSV로 저장합니다.

> 파일 → 다른 이름으로 저장 → 파일 형식에서 **CSV UTF-8(쉼표로 분리)(*.csv)** 선택

`CSV UTF-8`이 아닌 그냥 `CSV`로 저장하면 한글이 깨집니다. 꼭 UTF-8을 고르세요.

## 1. 백분위 기준표 — `norms.csv` (8/17 전달)

> **8/15 변경**: 국민체력100 원자료는 파일 다운로드가 아니라 API라서, **강인혁이 받아
> CSV 파일로 넘겨 드립니다.** 활용신청·인증키를 다루실 필요 없습니다.
> 받으실 것은 `kspo_measurements.csv` 파일과 **컬럼 목록**입니다.
> 자세한 건 `docs/데이터_확보_절차.md` 참고.

템플릿: `templates/체력기준표_템플릿.xlsx`

국민체력100 공개 데이터를 성별 × 나이대 × 측정항목으로 나눠, "이 값이면 상위 몇 %"인지
표로 만드는 일입니다.

### 열 구성

```
gender,age_band,item,percentile,value
M,30-34,grip,50,60
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `gender` | `M` 또는 `F` | 남/여. 한글로 쓰지 마세요 |
| `age_band` | `19-24` `25-29` `30-34` ... `60-64` | 국민체력100 인증기준과 같은 **5세 단위** (9구간) |
| `item` | 아래 5개 코드 | 측정 항목 |
| `percentile` | 숫자 | 백분위. **클수록 우수** |
| `value` | 숫자 | 그 백분위에 해당하는 측정값 |

### 측정 항목 코드

| 코드 | 항목 | 단위 |
| --- | --- | --- |
| `grip` | 상대악력 | % (악력 ÷ 체중 × 100) |
| `sit_up` | 교차윗몸일으키기 | 회 |
| `sit_reach` | 앉아윗몸앞으로굽히기 | cm |
| `shuttle_run` | 왕복오래달리기 | 회 |
| `standing_jump` | 제자리멀리뛰기 | cm (순발력) |

### 몇 줄이 필요한가

성별 2 × 나이대 **9** × 항목 5 = 90개 조합. 조합마다 백분위 점을 5개씩(10, 30, 50, 70, 90)
잡으면 **450줄**입니다. 템플릿에 이미 깔려 있으니 노란색 value 열만 채우시면 됩니다.

점을 더 촘촘히(5, 10, 20, ... 95) 잡으셔도 됩니다. 많을수록 진단이 정확해집니다.

### 주의

- 같은 조합 안에서 `percentile`이 커지면 `value`도 커져야 합니다.
  앱이 점과 점 사이를 직선으로 이어 계산하기 때문에, 순서가 뒤집히면 결과가 이상해집니다.
- **앉아윗몸앞으로굽히기는 음수가 나올 수 있습니다.** (-5cm 등) 정상입니다.
- 빈칸을 두지 마세요. 값이 없으면 그 줄을 통째로 빼시는 게 낫습니다.

### 오입력 제외 기준 (별도 문서)

원자료에는 비현실적인 값이 섞여 있습니다. 어떤 기준으로 걸렀는지
`templates/오입력_제외기준.md` 에 적어 주세요. **CSV에 열로 넣지 마세요.**

이 문서는 보고서에도 그대로 들어갑니다. 심사에서 데이터 신뢰도를 보는 부분입니다.

## 2. 강좌 태그표 — `courses.csv` (8/19 전달)

템플릿: `templates/강좌태그표_템플릿.xlsx`

공공 체육 강좌 목록에 "이 강좌가 어떤 체력요인을 키우는지" 표시하는 일입니다.

### 열 구성

```
course_id,title,facility,lat,lng,weekday,start_time,sport,tag_strength,tag_endurance,tag_flex,tag_cardio,tag_power
C001,직장인 코어 필라테스,마포구민체육센터,37.5563,126.9236,월,19:00,필라테스,1,1,1,0,0
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `course_id` | 문자열 | 고유 ID. 중복 금지 (C001, C002...) |
| `title` | 문자열 | 강좌명 |
| `facility` | 문자열 | 시설명 |
| `lat` / `lng` | 숫자 | 위도 / 경도. 소수점 4자리 이상 |
| `weekday` | `월`~`일` | **한 글자.** `월요일` 아님 |
| `start_time` | `HH:MM` | 24시간제. `19:00`, `09:30`. `7시` 아님 |
| `sport` | 문자열 | 종목 |
| `tag_strength` | `0` 또는 `1` | 근력 |
| `tag_endurance` | `0` 또는 `1` | 근지구력 |
| `tag_flex` | `0` 또는 `1` | 유연성 |
| `tag_cardio` | `0` 또는 `1` | 심폐지구력 |
| `tag_power` | `0` 또는 `1` | 순발력 |

### 태그 다는 요령 (여기가 추천 품질을 좌우합니다)

- **5개가 전부 0이면 그 강좌는 추천에서 아예 빠집니다.** 최소 하나는 1이어야 합니다.
- **후하게 주지 마세요.** 대부분이 `1,1,1,1,1`이면 추천이 무의미해집니다.
  "이 강좌가 **주로** 키우는 것"만 1로 두세요. 보통 강좌당 1~3개입니다.
- 참고 예시

| 종목 | 근력 | 근지구력 | 유연성 | 심폐 | 순발력 |
| --- | --- | --- | --- | --- | --- |
| 웨이트·근력강화 | 1 | 1 | 0 | 0 | 0 |
| 필라테스 | 1 | 1 | 1 | 0 | 0 |
| 요가 | 0 | 1 | 1 | 0 | 0 |
| 수영 | 1 | 1 | 0 | 1 | 0 |
| 에어로빅·줌바 | 0 | 1 | 1 | 1 | 0 |
| 배드민턴·탁구 | 0 | 0 | 0 | 1 | 1 |
| 태권도·검도 | 1 | 1 | 1 | 1 | 1 |
| 생활체조 | 0 | 1 | 1 | 0 | 0 |

- 주 2회 이상 강좌는 **요일별로 줄을 나눠** 주세요. `course_id`는 다르게 (C010, C011).
- 좌표는 시설 좌표면 됩니다. 강의실 단위까지 필요 없습니다.
  카카오맵에서 시설명 검색 → 우클릭 → "이 위치의 좌표" 로 확인할 수 있습니다.
- **퇴근 후 이용 가능한 야간(18:30 이후)·주말 강좌를 우선**으로 모아 주세요.
  낮 강좌만 잔뜩 있으면 추천 결과가 비어 버립니다.

## 3. 시설 주소표 — `facility_addresses.csv` (강좌표와 함께)

템플릿: `templates/시설주소표_템플릿.xlsx`

앱이 사용자에게 좌표 대신 주소를 보여주도록 바뀌어 새로 생긴 파일입니다.

```
facility,address
마포구민체육센터,서울특별시 마포구 월드컵로 235
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `facility` | 문자열 | **`courses.csv`의 `facility`와 글자까지 똑같아야** 연결됩니다 |
| `address` | 문자열 | 전체 주소. 형식 제약 없음 |

- 시설 하나당 한 줄. 같은 시설의 강좌가 여러 개여도 한 번만 적으면 됩니다.
- 주소를 못 찾은 시설은 **줄을 빼거나 `address`를 비워** 두세요.
  그 시설만 주소 없이 표시되고 나머지는 정상 동작합니다.
- 지금 저장소에는 자치구까지만 채운 샘플(`서울특별시 서초구`)이 들어 있습니다.
  전체 주소로 덮어써 주시면 앱 수정 없이 반영됩니다.

## 4. 판정 검증 (8/19~, 2회)

앱이 계산한 결과가 맞는지 엑셀 손계산과 대조하는 일입니다. **가장 중요한 작업입니다.**
데이터가 맞아도 계산이 틀리면 서비스 자체가 틀린 것이 됩니다.

### 방법

1. 브라우저로 앱을 엽니다 (아래 5번 참고)
2. 임의의 측정값을 넣고 진단합니다
3. 리포트의 **"100명 중 n등"** 표기를 봅니다
4. 엑셀에서 같은 값으로 백분위를 직접 계산합니다
5. `n등`이 `100 - 백분위`와 맞는지 확인합니다

> 예: 30대 남성 악력 백분위가 75라면 앱은 **"100명 중 25등"** 으로 표시해야 합니다.

### 다르면

리포트 시트에 **유형 = `판정 오류`** 로 적고, 아래를 함께 남겨 주세요.

- 입력한 값 전부 (성별, 나이, 측정값 8칸)
- 엑셀로 계산한 기대 백분위
- 앱이 보여준 등수

1회차 10건, 2회차도 10건 정도면 충분합니다. 나이대·성별을 골고루 섞어 주세요.

## 5. 앱을 직접 보는 법

강인혁이 보낸 `fitbalance` 폴더에서

- 윈도우: **실행_윈도우.bat** 더블클릭
- 맥: **실행_맥.command** 더블클릭
  (처음엔 "확인되지 않은 개발자" 경고 → 파일 **우클릭 → 열기**)

검은 창이 뜨고 브라우저가 자동으로 열립니다. 첫 실행은 1~2분 걸립니다.
끝낼 때는 검은 창을 닫으면 됩니다.

### 내가 만든 데이터를 직접 넣어보기

1. 검은 창을 닫아 서버를 끕니다
2. `data` 폴더의 `norms.csv` / `courses.csv` / `facility_addresses.csv` 를 내 파일로 바꿉니다
3. 다시 실행 파일을 더블클릭합니다

열 구성이 틀리면 검은 창에 오류가 뜨고 서버가 안 켜집니다. **그 화면을 캡처해서 보내주세요.**
어디가 틀렸는지 바로 알 수 있습니다.

## 6. 활용사례 보고서 초안 (8/20~)

템플릿: `templates/활용사례_보고서_초안.md`

제출용 문서의 뼈대입니다. 채워 주실 곳은 크게 셋입니다.

**시장 근거 수치** — 반드시 출처를 함께 적어 주세요. 기관명·자료명·연도·URL.
출처 없는 숫자는 심사에서 오히려 감점입니다.

**유사 서비스 조사** — 앱 이름과 URL을 실명으로. 무엇이 되고 무엇이 안 되는지,
우리와 어디가 다른지. 독창성 25%가 여기서 갈립니다.

**데이터 활용 설명** — 어떤 데이터를 어디에 썼는지. 1번의 오입력 제외 기준 문서를
그대로 붙이시면 됩니다.

## 자주 나오는 질문

**국민체력100 원자료에 백분위가 없어요** → 측정값 분포에서 직접 구하시면 됩니다.
값을 오름차순 정렬한 뒤 `PERCENTRANK` 함수를 쓰거나, 상위 10%/30%/50% 지점의 값을 뽑아
그 값을 `value`에, 해당 백분위를 `percentile`에 적으면 됩니다.

**나이대가 원자료와 안 맞아요** → 우리는 공단 인증기준과 같은 5세 단위를 씁니다.
원자료 구간이 다르면 가까운 구간으로 맞추시고, 어떻게 맞췄는지 오입력 제외 기준 문서에 적어 주세요.

**강좌를 어디서 구하나요** → 공공데이터포털의 공공체육시설 강좌 데이터,
각 구청·구민체육센터 홈페이지의 강좌 안내. 수도권 위주로 30~100개면 충분합니다.

**좌표를 모르겠어요** → 비워 두지 마시고 시설명만이라도 정확히 적어 주세요.
좌표는 제가 채울 수 있습니다. 다만 시설명이 틀리면 주소 연결이 깨집니다.
