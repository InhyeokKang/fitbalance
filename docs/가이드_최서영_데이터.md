# 최서영 가이드

읽는 데 5분. 이 문서 하나로 시작할 수 있게 썼습니다. 모르는 게 나오면 강인혁에게 물어보세요.

---

## 1. 우리가 만든 게 뭔가요

**직장인이 자기 몸 어디가 약한지 재고, 퇴근길에 다닐 수 있는 공공 체육 강좌를 받는 앱**입니다.
이름은 **fitbalance**입니다.

```
집에서 3가지 측정  →  또래 100명 중 몇 등인지 확인  →  약한 곳에 맞는
(줄자·초시계)         (국민체력100 기준표와 대조)      퇴근길 강좌·시설 추천
```

**공모전 출품작**이고, "공공데이터를 실제로 썼는가"가 심사에서 중요합니다.
그래서 앱에 들어간 숫자는 전부 출처가 있어야 합니다.

지금 상태는 이렇습니다.

| 데이터 | 어디서 | 상태 |
| --- | --- | --- |
| 체력 기준표 450행 | 국민체력100 측정 기록 15만 건 | ✅ 끝남 |
| 전국 공공체육시설 34,727곳 | 공공데이터포털 | ✅ 끝남 |
| 시설 주소·좌표 | 위와 같음 | ✅ 끝남 |
| 체력인증센터 78개소 | 국민체력100 공식 목록 | ✅ 끝남 |
| **강좌 시간표** | **공공데이터에 없음** | ❌ **최서영 담당** |

## 2. 처음 계획과 달라진 점 (꼭 읽어 주세요)

처음에는 최서영이 **기준표 만들기 + 강좌 수집 + 주소 수집**을 다 하기로 했었습니다.
그런데 진행하면서 상당 부분이 자동화돼서 **일이 많이 줄었습니다.**

| 처음 계획 | 지금 |
| --- | --- |
| 국민체력100 원자료 받아 백분위 기준표 만들기 | ❌ 안 해도 됨 (API로 자동 생성 완료) |
| 강좌 좌표를 지도에서 하나씩 찾기 | ❌ 안 해도 됨 (공공데이터에 좌표가 있음) |
| 시설 주소표 만들기 | ❌ 안 해도 됨 (3,753곳 자동 확보) |
| 강좌 태그 붙이기 | ⭕ **이건 해야 함** |
| **강좌 시간표 수집** | ⭕ **이게 핵심** |

**왜 시간표만 남았나요?**

전국 단위로 강좌 시간표를 공개하는 공공데이터가 **없습니다.** 확인해 봤습니다.

- 스포츠강좌이용권 강좌정보 → 취약계층 유·청소년 대상이고 시설명·주소가 없음
- 공공체육시설 데이터 → 시설명·주소·좌표·종목은 있는데 **시간표가 없음**

그래서 시설이 어디 있는지는 공공데이터로 다 채웠고, **"무슨 강좌가 몇 시에 열리는지"만
사람이 찾아야 합니다.** 그게 최서영 몫입니다.

## 5. 어떻게 채우나요

### 5-1. 시설 고르기

**퇴근 후에 갈 수 있는 곳** 위주로 고르세요. 우선순위는 이렇습니다.

1. **수영장, 생활체육관, 체력단련장** — 정기 강좌가 확실히 열립니다
2. 수도권 (서울·경기·인천) — 시연에서 주로 보여줄 지역입니다
3. 종목이 골고루 섞이게 (수영만 30개면 추천이 단조로워집니다)

### 5-2. 시간표 찾기

`facility` 열의 시설명을 그대로 검색하세요.

```
예)  "반포종합운동장체육센터 강좌"  로 검색
     → 시설 홈페이지나 서초구청 문화체육 안내에 시간표가 있습니다
```

찾을 곳은 대개 이렇습니다.

- 시설 자체 홈페이지의 **수강신청 / 프로그램 안내**
- 해당 구청·시청 홈페이지의 **문화체육 → 강좌**
- 지자체 통합예약 사이트

### 5-3. 세 칸 채우기

```
title        야간 수영 초급반          ← 실제 강좌 이름 그대로
weekday      월                        ← 한 글자! "월요일" 아님
start_time   19:00                     ← 24시간제! "저녁 7시" 아님
```

**주의**

- `weekday`는 **월 화 수 목 금 토 일** 중 한 글자만
- `start_time`은 **19:00** 형식 (09:30 처럼 0을 붙여야 함)
- 주 2회 강좌면 **줄을 나눠서** 두 줄로 (`course_id`는 다르게)
- **퇴근 후(18:30 이후)와 주말 강좌를 우선**으로 모아 주세요.
  낮 강좌만 있으면 추천 결과가 비어 버립니다

### 5-4. 태그 고치기

`tag_` 로 시작하는 5개 열은 **이 강좌가 어떤 체력요인을 키우는지**를 0 또는 1로 적는 것입니다.

지금은 종목만 보고 넣은 **임시값**이라, 실제 강좌를 보고 고쳐 주세요.
예를 들어 "체육관"으로 되어 있어도 실제로는 요가일 수도 배드민턴일 수도 있습니다.

| 종목 | 근력 | 근지구력 | 유연성 | 심폐 | 순발력 |
| --- | --- | --- | --- | --- | --- |
| 수영 | 0 | 1 | 1 | 1 | 0 |
| 요가·필라테스 | 1 | 1 | 1 | 0 | 0 |
| 배드민턴·테니스 | 0 | 0 | 0 | 1 | 1 |
| 웨이트·근력교실 | 1 | 1 | 0 | 0 | 0 |
| 스피닝·에어로빅 | 0 | 1 | 0 | 1 | 0 |
| 태권도·검도 | 1 | 1 | 1 | 1 | 1 |
| 생활체조 | 0 | 1 | 1 | 0 | 0 |
| 골프·파크골프 | 0 | 0 | 1 | 0 | 1 |

**태그 다는 요령 — 여기가 추천 품질을 좌우합니다**

- **5개가 전부 0이면 그 강좌는 추천에서 아예 빠집니다.** 최소 하나는 1이어야 합니다
- **후하게 주지 마세요.** 대부분이 `1,1,1,1,1`이면 추천이 무의미해집니다.
  "이 강좌가 **주로** 키우는 것"만 1로 두세요. 보통 강좌당 1~3개입니다

### 5-5. 안 쓸 줄은 지우기

30~100줄을 채웠으면 **나머지 줄은 전부 삭제**하고 저장하세요.
CSV 형식으로, **UTF-8** 로 저장해 주세요.

## 6. 못 찾으면 어떻게 하나요

시간표를 도저히 못 찾는 시설이 많을 겁니다. **정상입니다.** 그럴 때는

- 그 줄은 지우고 다른 시설로 넘어가세요
- 30개만 되어도 시연에는 충분합니다
- 다만 **어느 지역·종목에서 특히 못 찾았는지**는 리포트에 적어 주세요.
  "공공데이터에 시간표가 없다"는 것을 뒷받침하는 근거가 됩니다

## 8. 리포트

`docs/리포트_최서영_데이터.md` 에 작업 과정을 적어 주세요.

**왜 필요한가요?** 심사에서 "이 데이터 어디서 났나요", "이 태그는 무슨 기준인가요"를
물어봅니다. 그때 답할 근거가 이 문서입니다. 활용사례 보고서에도 그대로 들어갑니다.

적을 것은 세 가지입니다.

1. 강좌를 **어디서** 찾았는지 (사이트 이름)
2. 태그를 **어떤 기준으로** 붙였는지
3. 못 찾은 것은 **왜** 못 찾았는지
