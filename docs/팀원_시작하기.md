# 팀원이 여기부터 읽으세요

한서연·최서영이 처음 보는 문서입니다. 3분이면 됩니다.

---

## 우리가 만든 것

**fitbalance** — 직장인이 자기 몸 어디가 약한지 재고, 퇴근길에 다닐 수 있는
공공 체육 강좌를 받는 안드로이드 앱입니다.

```
집에서 3가지 측정  →  또래 100명 중 몇 등인지 확인  →  약한 곳에 맞는
(줄자·초시계)         (국민체력100 기준표와 대조)      퇴근길 강좌·시설 추천
```

**관광·체육 공공데이터 공모전** 출품작입니다. 심사에서 "공공데이터를 실제로 썼는가"가
가장 중요해서, 앱에 나오는 숫자에는 전부 출처가 있습니다.

| 데이터 | 출처 | 규모 |
| --- | --- | --- |
| 체력 기준표 | 국민체육진흥공단 국민체력100 측정결과 | 측정 기록 15만 건 → 450행 |
| 공공체육시설 | 공공데이터포털 공공체육시설 상세 정보 | 전국 34,727곳 |
| 체력인증센터 | 국민체력100 공식 목록 | 전국 78개소 |
| 강좌 시간표 | 전국평생학습강좌표준데이터 | 최서영 담당 (도구로 수집 후 검증) |

## 앱 켜 보기 (둘 다 먼저 이것부터)

**https://inhyeokkang.github.io/fitbalance/**

| 쓰는 컴퓨터 | 누를 버튼 | 받은 뒤 |
| --- | --- | --- |
| 윈도우 | Windows용 받기 | 압축 풀고 `설치.bat` 더블클릭 |
| 맥 | macOS용 받기 | 압축 풀고 `설치.command` 더블클릭 |
| 안드로이드 폰 | APK 받기 | 폰에 옮겨 설치 (가장 빠름) |

**처음 실행하면 약 2GB를 내려받습니다. 10~20분 걸립니다.**
컴퓨터 안에 가짜 안드로이드 폰(에뮬레이터)을 까는 과정이라 그렇습니다.
한 번만 그렇고 다음부터는 켜기만 합니다.

**검은 창을 닫지 마세요.** 그 창이 추천 서버입니다. 닫으면 앱의 진단·추천·검색이 멈춥니다.

막힐 때

| 증상 | 어떻게 |
| --- | --- |
| 윈도우 "PC 보호" 파란 창 | 추가 정보 → 실행 |
| 맥 "확인되지 않은 개발자" | 파일 오른쪽 클릭 → 열기 |
| "파이썬이 없습니다" | python.org 에서 설치 후 다시 실행 |
| 앱에 "서버 연결을 확인해 주세요" | 검은 창이 닫혔는지 확인 |
| 한글이 안 쳐짐 | 자판 아래 지구본 키를 누르면 한글로 바뀜 |

> 안 되면 그냥 강인혁에게 말해 주세요. 설치 파일을 깨끗한 PC에서 처음부터
> 돌려본 적이 없어서, 처음 걸리는 사람이 생기면 바로 고쳐야 합니다.
