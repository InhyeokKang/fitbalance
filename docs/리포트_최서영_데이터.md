## 5. 태그를 붙인 기준

`tag_strength` 등 5개 열을 0/1로 정한 근거입니다.

**기본 원칙**

- 그 강좌가 **주로** 키우는 요인만 1로 두었습니다 (강좌당 1~3개)
- 5개가 전부 0이면 추천에서 빠지므로 최소 하나는 1로 두었습니다

**종목별로 정한 값**

| 종목 | 근력 | 근지구력 | 유연성 | 심폐 | 순발력 | 이렇게 정한 이유 |
| --- | --- | --- | --- | --- | --- | --- |
| 수영 | 0 | 1 | 1 | 1 | 0 | |
| | | | | | | |
| | | | | | | |

**애매했던 것과 그 판단**

| 강좌 | 무엇이 애매했나 | 어떻게 정했나 |
| --- | --- | --- |
| (예) 실버 요가 | 유연성만? 근력도? | 저강도라 근력은 0으로 둠 |
