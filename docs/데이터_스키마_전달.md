# 데이터 스키마 전달 문서 (최서영 트랙용)

작성: 강인혁 / 2026-08-14
관련 일정: 8/17 기준표 전달, 8/19 태그표 전달

**열 이름과 순서를 그대로 지켜 주세요.** 앱 서버가 기동할 때 열 구성을 검사하고, 다르면
적재를 거부합니다. 열을 추가하거나 이름을 바꾸면 그날 빌드가 통째로 멈춥니다.
값이 이상하거나 항목이 부족하면 스키마를 바꾸지 말고 저에게 먼저 알려 주세요.

파일 형식: **CSV, UTF-8 인코딩**. 엑셀에서 "다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)".

현재 저장소의 `data/norms.csv`, `data/courses.csv`가 같은 스키마의 샘플입니다.
그 파일을 열어 내용만 실데이터로 바꾸면 가장 안전합니다.

## 1. 백분위 기준표 — `norms.csv`

```
gender,age_band,item,percentile,value
M,30s,grip,50,60
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `gender` | `M` 또는 `F` | 남/여. 한글 아님 |
| `age_band` | `20s` `30s` `40s` `50s` | 19~29 / 30~39 / 40~49 / 50~64세 |
| `item` | 아래 5개 코드 중 하나 | 측정 항목 |
| `percentile` | 숫자 | 하위 기준 백분위. **값이 클수록 우수** |
| `value` | 숫자 | 그 백분위에 해당하는 측정값 |

### item 코드와 단위

| `item` | 항목명 | 단위 | 비고 |
| --- | --- | --- | --- |
| `grip` | **상대악력** | % | 악력(kg) ÷ 체중(kg) × 100. 절대악력 아님 |
| `sit_up` | 교차윗몸일으키기 | 회/60초 | |
| `sit_reach` | 앉아윗몸앞으로굽히기 | cm | 음수 가능 |
| `shuttle_run` | 왕복오래달리기 | 회 | 20m 셔틀런 |
| `one_leg_stand` | 눈감고외발서기 | 초 | |

### 필요한 행 수

성별 2 × 나이대 4 × 항목 5 × 백분위 5개(10, 25, 50, 75, 90) = **200행**.
백분위 지점은 5개보다 많아도 됩니다(많을수록 진단이 정밀해집니다). 다만 **항목마다
최소 5개 지점**은 있어야 합니다. 사용자 값이 지점 사이에 오면 서버가 선형 보간합니다.

### 주의

- `percentile`은 "상위 %"가 아니라 **하위 기준**입니다. 상위 10%에 해당하는 우수한 값은
  `percentile=90` 행에 넣습니다. 헷갈리면 "이 값보다 낮은 사람이 몇 %인가"로 생각하세요.
- 같은 (gender, age_band, item) 안에서 `percentile`이 커질수록 `value`도 커져야 합니다.
  거꾸로 들어가면 진단이 뒤집힙니다.
- 오입력 제외 기준(비현실적 키·체중 등)은 **별도 시트에 문서로** 남겨 주세요.
  CSV에 열로 넣지 마세요.

## 2. 강좌 태그표 — `courses.csv`

```
course_id,title,facility,lat,lng,weekday,start_time,sport,tag_strength,tag_flex,tag_cardio,tag_balance
C001,직장인 코어 필라테스,마포구민체육센터,37.5563,126.9236,월,19:00,필라테스,1,1,0,1
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `course_id` | 문자열 | 강좌 고유 ID. 중복 금지 |
| `title` | 문자열 | 강좌명 |
| `facility` | 문자열 | 시설명 |
| `lat` / `lng` | 숫자 | 위도 / 경도. 소수점 4자리 이상 |
| `weekday` | `월`~`일` | 한 글자. `월요일` 아님 |
| `start_time` | `HH:MM` | 24시간제. `19:00`, `09:30`. `7시` 아님 |
| `sport` | 문자열 | 종목 |
| `tag_strength` | `0` 또는 `1` | 근력 |
| `tag_flex` | `0` 또는 `1` | 유연성 |
| `tag_cardio` | `0` 또는 `1` | 심폐지구력 |
| `tag_balance` | `0` 또는 `1` | 평형성 |

### 주의

- 태그 4개가 **전부 0인 강좌는 추천에서 아예 빠집니다.** 최소 하나는 1이어야 합니다.
- 태그를 너무 후하게 주면(대부분 1,1,1,1) 추천이 무의미해집니다.
  "이 강좌가 주로 키우는 것"만 1로 두는 편이 결과가 좋습니다. 보통 강좌당 1~3개.
- 주 2회 이상 강좌는 요일별로 행을 나눠 주세요(`course_id`는 다르게).
- 좌표는 시설 좌표면 됩니다. 강의실 단위까지 필요 없습니다.

## 3. 시설 주소표 — `facility_addresses.csv` (신규)

앱이 사용자에게 좌표 대신 **주소**를 보여주도록 바뀌었습니다.
`courses.csv` 스키마는 계약대로 고정이라 열을 추가할 수 없어, 주소는 별도 파일로 받습니다.

```
facility,address
마포구민체육센터,서울특별시 마포구 월드컵로 235
```

| 열 | 값 | 설명 |
| --- | --- | --- |
| `facility` | 문자열 | **`courses.csv`의 `facility`와 글자까지 똑같아야** 합니다. 이 값으로 연결합니다 |
| `address` | 문자열 | 전체 주소. 형식 제약 없음 |

### 주의

- 시설 하나당 한 행. 같은 시설의 강좌가 여러 개여도 주소는 한 번만 적으면 됩니다.
- 주소를 못 찾은 시설은 **행을 빼거나 `address`를 비워** 두세요.
  그 시설은 앱에서 주소 줄이 생략될 뿐, 나머지는 정상 동작합니다.
- 지금 저장소에는 자치구까지만 채운 샘플(`서울특별시 서초구`)이 들어 있습니다.
  전체 주소로 덮어써 주시면 앱·서버 수정 없이 그대로 반영됩니다.

## 4. 전달 방법

파일 그대로 단톡에 올려 주시면 됩니다. 받으면 제가 스키마 검증을 돌리고,
실데이터 기준 진단 결과 3건을 뽑아 공유하겠습니다.

판정 검증(8/19~) 때 대조하실 값은 앱 리포트의 **"100명 중 n등"** 표기입니다.
이 숫자는 `100 - percentile`입니다. 엑셀 손계산과 다르면 리포트 유형을 `판정 오류`로
남기고, 입력값과 기대 백분위를 함께 적어 주세요.
