# 측정 현실성 검토 — 사용자가 이 값들을 어떻게 넣는가

작성: 2026-08-15

지금 앱은 측정값 8개를 사용자가 직접 입력하게 되어 있다.
**그런데 그 값을 어디서 얻는지가 설계에 없었다.** 이 문서는 그 구멍을 메우기 위한 검토다.

---

## 1. 문제 — 집에서 잴 수 있는 항목이 거의 없다

국민체력100 성인기 인증항목을 도구 기준으로 나눠 보면 이렇다.

| 항목 | 필요한 것 | 집에서 가능? |
| --- | --- | --- |
| 상대악력 | **악력계(dynamometer)** | ✗ |
| 20m 왕복오래달리기 | **20m 직선 공간 + 페이스 음원** | ✗ |
| 교차윗몸일으키기 | 매트, 60초 타이머 | △ 자세 기준이 까다로움 |
| 앉아윗몸앞으로굽히기 | **좌전굴 측정기** (자로 대체 시 오차) | △ |
| 제자리멀리뛰기 | 매트, 줄자, 충분한 공간 | △ |
| 10m 왕복달리기 | 10m 공간, 표적 | △ |

**정확히 재려면 사실상 전부 장비가 필요하다.** "측정값 8가지를 넣으세요"라는 지금 화면은
사용자가 이미 그 숫자를 갖고 있다고 가정하는데, 그 가정이 성립하지 않는다.

심사에서도 "이 값을 사용자가 어떻게 구하나요"라는 질문이 나올 가능성이 높다.

---

## 2. 그런데 공단이 이미 무료로 재 준다

| 항목 | 내용 |
| --- | --- |
| 체력인증센터 | **전국 75개소** |
| 이용료 | **무료** |
| 대상 | 만 13세 이상 대한민국 국민 누구나 |
| 결과 | 측정 결과지 + 인증 등급 + 운동처방 |
| **출장전담반** | **원하는 장소로 출장해 다수 인원 측정** |

출처: [국민체력100 소개](https://nfa.kspo.or.kr/intro/intro.kspo),
[체력인증센터 찾기](https://nfa.kspo.or.kr/intro/centerList.kspo)

이게 판을 바꾼다. 사용자가 장비를 살 필요가 없다. **이미 존재하는 무료 공공서비스에서
받은 결과지의 숫자를 앱에 옮겨 적으면 된다.**

그리고 **출장전담반**은 직장인 타깃에 정확히 맞는다. 회사로 측정팀이 온다는 뜻이다.

---

## 3. 공단의 자가측정은 어떻게 하고 있나

국민체력100 사이트의 "자가체력측정"은 5단계인데, **대부분이 설문이다.**

1. 사전신체상태설문지 (PAR-Q) — 운동 가능 여부 확인 7문항
2. 운동동기 설문지
3. **국제신체활동 설문지 (IPAQ)**
4. 노쇠 설문지
5. 자가 체력측정 평가결과 등록

출처: [자가체력측정](https://nfa.kspo.or.kr/measure/self/selectSelfStep1.kspo)

즉 공단조차 **장비 없는 자가측정은 설문으로 대신하고 있다.**
우리가 자가측정 경로를 만든다면 같은 방향이 타당하다.

---

## 4. 제안 — 입력 경로를 둘로 나눈다

### 경로 A. 체력인증센터 결과 입력 (정밀 진단)

- 체력인증센터에서 무료 측정 → 결과지의 숫자를 앱에 입력
- 국민체력100 기준표와 **직접 대조** → 백분위·약점 판정이 정확
- 지금 만들어 둔 입력 화면을 그대로 쓴다
- 앱에 **"가까운 체력인증센터 찾기"** 를 넣어 예약 페이지로 연결

### 경로 B. 간편 자가진단 (참고용)

측정값이 없는 사용자를 위한 진입로. 결과에 **"참고용"** 을 명시한다.

| 체력요인 | 자가 문항 / 간이 측정 | 도구 |
| --- | --- | --- |
| 근력·근지구력 | 30초 의자 앉았다 일어서기 횟수 | 의자 |
| 유연성 | 앉아 앞으로 굽히기 (자 사용, 손끝~발끝 cm) | 줄자 |
| 심폐지구력 | IPAQ 기반 주간 신체활동량 + 계단 3층 오를 때 숨참 정도 | 없음 |
| 순발력·민첩성 | 주관적 문항 (버스 놓칠 때 뛸 수 있는지 등) | 없음 |

- 결과는 **"약점 추정"** 으로만 제시하고, 정확한 진단은 센터 측정을 안내
- 추천 강좌는 동일하게 제공 (약점 요인만 알면 추천은 돌아간다)

### 왜 이 구조가 공모전에 유리한가

1. **공공서비스 이용을 늘린다.** 체력인증센터는 무료인데 인지도가 낮다.
   앱이 "당신은 근력이 약할 수 있습니다 → 무료로 정확히 재보세요 → 가까운 센터는 여기"
   로 이어주면, **공공데이터 활용을 넘어 공공서비스 연계**가 된다.
2. **출장전담반 = B2B 확장 서사.** 기업 단체 측정 → 그 회사 직원들의 앱 가입 →
   회사 인근 강좌 추천. 직장인 타깃과 정확히 맞물린다.
3. **진입장벽 해소.** 경로 B가 없으면 "센터 안 가본 사람은 앱을 못 쓴다"가 된다.

---

## 5. 결정이 필요한 것

- [ ] 경로 B(간편 자가진단)를 데모에 넣을 것인가, 아니면 경로 A만 두고 기획으로만 설명할 것인가
- [ ] 넣는다면 자가 문항을 몇 개로 할 것인가 (5~8문항 권장)
- [ ] "가까운 체력인증센터 찾기" 연결을 넣을 것인가
      (센터 목록은 [공공데이터포털 체력인증센터 현황]으로 확보 가능)

> 경로 A만으로도 데모는 성립한다. 다만 심사에서 "사용자가 이 숫자를 어떻게 구하나"라는
> 질문이 나올 때, 최소한 **답변은 준비되어 있어야 한다.**
> 화면이 없더라도 발표 자료에는 이 구조를 넣는 편이 안전하다.
