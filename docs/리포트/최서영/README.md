# 최서영 리포트 폴더

## 어떻게 쓰나요

**매일 하나씩** 파일을 만듭니다.

1. `_양식.md` 를 복사한다
2. 파일 이름을 그날 날짜로 바꾼다 — `2026-08-18.md`
3. 그날 돌린 것, 나온 숫자, 이상했던 것을 적는다

날짜 파일은 미리 만들어 뒀습니다. **열어서 채우기만 하면 됩니다.**

| 파일 | 무엇 |
| --- | --- |
| [_양식.md](_양식.md) | 복사해서 쓸 하루치 양식 |
| [2026-08-18.md](2026-08-18.md) | 8/18 일지 |
| [2026-08-19.md](2026-08-19.md) | 8/19 일지 |
| [2026-08-20.md](2026-08-20.md) | 8/20 일지 |
| [2026-08-21.md](2026-08-21.md) | 8/21 일지 |
| [종합_데이터검증.md](종합_데이터검증.md) | **제출용.** 출처·표본검사·커버리지·판정규칙·한계 |

## 일지와 종합, 뭐가 다른가요

| | 일지 (날짜 파일) | 종합 |
| --- | --- | --- |
| 언제 | 매일 | 마지막에 한 번 |
| 무엇 | 그날 돌린 명령, 나온 숫자, 막힌 것 | 정확도 표, 시도별 커버리지, 데이터 한계 |
| 누가 보나 | 강인혁 (같이 고치려고) | 심사·활용사례 보고서 |

일지는 **터미널 출력을 그대로 붙여넣어도 됩니다.** 종합은 정리해서 씁니다.

## 숫자를 꼭 남겨 주세요

심사에서 "이 데이터 믿을 만한가요"를 반드시 묻습니다.
그때 **"무작위 30건 중 28건이 일치했다"** 처럼 답할 수 있어야 합니다.

그래서 일지에는 인상이 아니라 **숫자**를 적어 주세요.

```
나쁜 예:  좌표가 대체로 맞는 것 같다
좋은 예:  30건 중 26건이 동까지 일치, 4건은 시군구까지만 (오차 2~4km)
```

무엇을 확인해야 하는지는 [가이드](../../가이드_최서영_데이터.md)의 5번을 보세요.
