## 강인혁 답 (2026-08-24)

**태그 쏠림** — 판단이 맞습니다. 저장소 도구(`build_courses_from_lessons.py`)에
그대로 반영했습니다. 요가 `flex+endurance` → `flex+strength`, 볼링 `power` →
`power+strength`. 보내 주신 `courses.csv` 의 태그와 도구가 만든 태그가 3,217줄
전부 일치하는 것까지 확인했습니다.

> 로컬 스크립트만 고치면 도구를 다시 돌릴 때 되돌아갑니다. 다음부터는 고친 파일도
> 같이 보내 주시거나 PR 로 올려 주세요.

다만 `tag_power` 는 244건(7.6%)으로 여전히 적습니다. 순발력이 약점으로 나온 사용자에게
줄 강좌가 부족합니다. 원자료에 순발력 종목이 적은 게 원인이라 데이터로는 해결되지
않습니다. 이 경우 시설 추천으로 넘기는 쪽을 검토하겠습니다.

**"장소명이 뭉뚱그려져 같은 장소에 여러 강좌가 묶인다"** — 이게 가장 중요한 발견이었습니다.
장소명 문제가 아니라 **좌표 문제**였습니다.

3,217건이 고유 좌표 **156개**에 몰려 있었습니다. 의정부 58개 시설의 346강좌가 좌표
하나를 공유했습니다. 원인은 제가 좌표를 붙이는 방식입니다. 강좌의 도로명주소에는
동 이름이 없어서(`관촉로 113-23`) 동 단위 매칭이 거의 안 맞고, 전부 시군구 대표점으로
떨어졌습니다.

실측 오차를 냈습니다. **시군구 중심점과 실제 시설의 거리가 중앙값 6.5km,
90퍼센타일 16.4km** 입니다. 앱은 퇴근 동선 3km 로 추천하므로 이 오차로는 추천이
성립하지 않습니다.

표본 검사에서 "좌표 30개 중 29개 일치" 가 나온 건 검사가 잘못돼서가 아닙니다.
도시 단위로는 맞기 때문에 표본 대조로는 이게 안 잡힙니다. 잡으려면 같은 시군구 안에서
시설끼리 좌표가 겹치는지를 봐야 합니다.

**고친 방법** — 주소를 좌표로 직접 바꾸는 도구를 새로 만들었습니다
(`tools/geocode_addresses.py`).

384개 주소 전부 좌표를 찾았고, 88%의 강좌가 1km 이상 옮겨졌습니다.

**지역 분포** — "실제 개설 비율이 반영된 팩트" 라는 판단은 맞습니다. 다만 광주 170건과
전남 전체는 팩트가 아니라 8/18 답에 적은 버그였습니다. 고친 도구로 **`fetch_lessons.py`
부터 다시 돌려 주세요.** 광주·전남이 살아나고 끝난 강좌가 빠집니다. 지금 저장소의
`courses.csv` 는 보내 주신 3,217건에 새 좌표만 붙인 것이라 광주·전남은 아직 비어 있습니다.

```
python tools/fetch_lessons.py
python tools/build_courses_from_lessons.py
python tools/geocode_addresses.py
python tools/build_courses_from_lessons.py
```

세 번째에서 새 주소의 좌표를 받고, 네 번째에서 그 좌표를 붙입니다.
좌표 캐시(`data/address_coords.csv`)는 저장소에 있으니 이미 변환된 384개는
다시 부르지 않습니다.
