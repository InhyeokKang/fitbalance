## 1. 진단 순위가 기준표와 맞는가

무작위 40명 × 5항목 = 200건을 만들어, 앱이 낸 순위와 `data/norms.csv` 를
직접 선형보간한 값을 대조했습니다.

| | |
| --- | --- |
| 기준표 범위 안 | 114건 — **113건 일치**, 1건은 경계값(차이 9) |
| 기준표 범위 밖 | 86건 — 아래 참고 |

**찾은 문제: 경계에서 순위가 절벽처럼 튀었습니다.**

기준표는 10·25·50·75·90 백분위 다섯 점뿐입니다. 예전 코드는 그 바깥을 곧장
1 또는 99로 잘라서, 표 하한에서 한 칸만 낮아도 90등이 99등이 됐습니다.
인구의 20%가 이 바깥에 있으므로 그냥 둘 수 없었습니다.

가장 바깥 구간의 기울기를 이어 붙이도록 고쳤습니다. 지금은 이렇게 나옵니다.

```
교차윗몸일으키기 (남 30~34세, 표 하한 29회 / 상한 56회)
  26회 -> 96등    54회 -> 15등
  27회 -> 94등    55회 -> 12등
  28회 -> 92등    56회 -> 10등  <- 표 상한
  29회 -> 90등    57회 ->  8등
  30회 -> 88등    58회 ->  5등
```

## 2. 추천이 납득되는가

**찾은 문제 1: 영화 상영이 운동 강좌로 추천됐습니다.**

`자전거 탄 소년(12세 관람가)` 이라는 영화가 제목의 "자전거" 때문에 스피닝으로
잡혔습니다. 같은 부분 문자열 오탐이 더 있었습니다.

| 잘못 잡힌 것 | 왜 |
| --- | --- |
| 도자기공예 → 기공 | "도자**기공**예" |
| 금정구평생학습관 → 테니스 | "금**정구**" |
| 걷기 지도자 2급 자격증 → 걷기 | 자격증 과정은 수강이 아니다 |

종목 판정 규칙에서 `정구` 를 빼고(테니스가 이미 있음), `기공` 은 국학기공·기공체조·
단전호흡·태극권만 인정하도록 좁혔습니다. 공예·영화·자격증 등은 아예 수집 단계에서
제외합니다. **지금 오탐 0건입니다.**

**찾은 문제 2: 어린이·시니어 강좌가 직장인에게 추천됐습니다.**

`튼튼 키즈요가`, `실버줌바`, `청소년K-POP댄스` 같은 것이 206건 있었습니다.
직장인 앱이므로 제외했습니다.

정리 결과 3,217건 → **2,945건**.

## 3. 지방에서도 되는가

전국 주요 14개 도시에서 퇴근 18:30 · 3km 조건으로 호출했습니다.

**찾은 문제: 14곳 중 7곳이 0건이었습니다.**

평생학습 강좌는 주간 위주라 퇴근 후 시작하는 것이 전체의 19%뿐입니다.
데이터로는 해결되지 않습니다. 대신 시간표에 매이지 않는 공공체육시설이
어느 도시에나 13~20곳 잡히므로, 강좌가 0건일 때 그쪽을 바로 권하도록 바꿨습니다.

```
이 시간·거리에 맞는 강좌가 없습니다.
대신 시간표 없이 갈 수 있는 공공체육시설이 31곳 있습니다.
   [ 가까운 공공시설 31곳 보기 ]
```

예전에는 "최대 거리를 넓히거나 퇴근 시각을 조정해 보세요" 만 띄웠습니다.
사용자가 할 수 있는 게 없는 막다른 길이었습니다.

## 4. 시연 시나리오

둘 다 대구 수성구, 퇴근 18:00, 3km 입니다. 만촌평생학습센터가 0.2km 라 지도에서도 잘 보입니다.

### 시나리오 A — 약점 보완 (주 흐름)

**입력**: 남 34세 / 78kg / 악력 40kg · 윗몸 30회 · 앞으로굽히기 2.0cm · 왕복달리기 38회 · 멀리뛰기 180cm

**결과**: 하체 기능 저하형 · 약점 순발력·근지구력

```
[단기강좌]셔플댄스        만촌평생학습센터  월 19:00  0.2km
댄스스포츠 초급(야간)     만촌평생학습센터  수 19:00  0.2km
댄스스포츠 중급(야간)     만촌평생학습센터  화 19:00  0.2km
```

**말할 것**: 국민체력100 실측 15만 건으로 또래 순위를 내고, 약한 요인에 맞는 강좌를
퇴근 동선에서 고릅니다. 전부 공공데이터입니다.

### 시나리오 B — 이미 좋은 사람 (차별점)

**입력**: 여 29세 / 55kg / 악력 34kg · 윗몸 45회 · 앞으로굽히기 22.0cm · 왕복달리기 70회 · 멀리뛰기 190cm

**결과**: 균형 양호형 · `profile=maintain`

```
필라테스(주말)                    만촌평생학습센터  토 10:00  0.2km
밸런스 바로잡는 청년필라테스      만촌평생학습센터  금 19:00  0.2km
```

**말할 것**: 다 좋은 사람에게 "당신은 약점이 없습니다" 로 끝내지 않고, 지금 수준을
이어 갈 곳을 고릅니다. 화면 문구도 보완이 아니라 유지로 바뀝니다.

### 시나리오 C — 강좌가 없을 때 (약점을 강점으로)

**입력**: 시나리오 A 와 같되 직장을 서울 강남으로

**결과**: 강좌 0건 → 공공체육시설 31곳 안내

**말할 것**: 평생학습 강좌는 주간 위주라 퇴근 후에 없는 지역이 많습니다. 그 사실을
숨기지 않고, 시간표 없이 갈 수 있는 공공체육시설로 연결합니다.
