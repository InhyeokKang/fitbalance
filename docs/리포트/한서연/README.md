# 한서연 리포트 폴더

## 어떻게 쓰나요

**매일 하나씩** 파일을 만듭니다.

1. `_양식.md` 를 복사한다
2. 파일 이름을 그날 날짜로 바꾼다 — `2026-08-18.md`
3. 그날 본 것과 찾은 것을 적는다

날짜 파일은 미리 만들어 뒀습니다. **열어서 채우기만 하면 됩니다.**

## 일지와 종합, 뭐가 다른가요

| | 일지 (날짜 파일) | 종합 |
| --- | --- | --- |
| 언제 | 매일 | 마지막에 한 번 |
| 무엇 | 그날 찾은 것, 그날 본 화면 | 진단 결과 10건 대조, 지역별 확인, 시연 시나리오 |
| 누가 보나 | 강인혁 (고치려고) | 심사·발표 자료 |

일지는 **날것 그대로** 적으면 됩니다. 종합은 정리해서 씁니다.

## 한 건 적는 법

이 다섯 줄이면 충분합니다.

```
### [높음] 부산으로 바꾸면 강좌가 안 나옴
- 어떻게 하면: 톱니바퀴 → 직장 부산 서면, 집 부산 해운대 → 저장 → 강좌 보기
- 나온 것: "조건에 맞는 강좌가 없습니다"
- 나와야 할 것: 부산 강좌 몇 개
```

**"어떻게 하면"을 꼭 적어 주세요.** 강인혁이 똑같이 따라 해서 재현해야 고칠 수 있습니다.
이게 없으면 못 고칩니다.

중요도는 세 단계로만 나눕니다.

| | 뜻 |
| --- | --- |
| 높음 | 앱이 꺼지거나, 결과가 틀렸거나, 시연 때 보여줄 화면이 안 됨 |
| 보통 | 불편하지만 넘어갈 수 있음 |
| 낮음 | 오타, 문구, 색 |

무엇을 봐야 하는지는 [가이드](../../가이드_한서연_검증.md)의 5번을 보세요.
