# 최종 역할 분담 & 일일 계획 (8/14 금 ~ 8/21 금)

**구조**: 개발·배포는 단독 트랙, 검증과 데이터·보고서는 별도 트랙. 세 트랙은 매일 빌드와 카톡 체크인으로만 만나고 회의는 없음.

**데모 v0.1 (8/14 완성 목표) 범위**: 입력 → 진단 리포트 → 강좌 추천 3개 흐름 + 상세·설정, 샘플 데이터, 로컬 서버 기준. 지도 화면과 실서버 배포는 데모 범위 밖(주중 진행).

---

## 1. 역할

### 강인혁 — 개발·배포 트랙
- 안드로이드 앱 + 백엔드 개발, 서버 배포
- 플레이 콘솔: 개발자 계정·본인인증·Android 개발자 인증, 앱 등록정보/심사 대응, 비공개 테스트 트랙 게시
- 매일 저녁 설치 가능한 빌드(APK) 단톡 공유 — 이게 검증 트랙의 입력물

### 한서연 — 검증 트랙
- 매일 빌드 설치 → **양식대로 리포트 제출** (유형: `동작 오류`)
- 심각도 기준: 앱이 죽거나 진행 불가 = `막힘` / 기능은 되는데 이상함 = `불편` / 오타·정렬 = `사소`
- `막힘`은 발견 즉시 단톡 태그, 나머지는 당일 23시까지 시트 기입

### 최서영 — 데이터·보고서 트랙 (전부 엑셀 작업)
- **백분위 기준표**: 국민체력100 공개 데이터를 성별×나이대×측정항목으로 나눠 "이 값이면 상위 몇 %"인지 표로 작성. **전달받은 CSV 스키마(열 이름·순서) 그대로 저장.** 오입력값(비현실적 키·체중 등) 제외 기준도 명시
- **강좌 태그표**: 공공 체육 강좌 목록에 강좌별 체력요인 태그(근력/유연성/심폐지구력/평형성, 0/1) 부여. 동일하게 스키마 준수
- **판정 검증**: 앱 출력과 엑셀 손계산을 대조해 내용이 틀린 경우 리포트 제출 (유형: `판정 오류`)
- **제출용 활용사례 보고서 초안**: 시장 근거 수치(원자료 출처 명시), 유사 서비스 조사 포함
