# 데이터 확보 절차 (2026-08-15 변경)

기존 계획은 최서영이 국민체력100 원자료를 직접 내려받아 백분위 기준표까지 만드는 것이었다.
그런데 이 데이터는 **파일 다운로드가 아니라 REST API**이고 활용신청·인증키가 필요하다.
API 호출은 개발 쪽에서 하는 편이 훨씬 빠르므로 **역할을 조정한다.**

---

## 바뀐 분담

| 단계 | 전 | 후 |
| --- | --- | --- |
| 활용신청·인증키 발급 | 최서영 | **강인혁** |
| API 호출·원자료 수집 | 최서영 | **강인혁** (`tools/fetch_kspo.py`) |
| 오입력 제외 기준 정하기 | 최서영 | 최서영 (그대로) |
| 백분위 산출 | 최서영 | 최서영 (원자료 파일을 받아서) |
| 판정 검증 | 최서영 | 최서영 (그대로) |
| 강좌 태그표·주소표 | 최서영 | 최서영 (그대로) |

**최서영은 API를 다룰 필요가 없다.** 강인혁이 넘긴 CSV 파일 하나로 시작한다.

## 강인혁이 할 일

### 1. 활용신청 (오늘)

https://www.data.go.kr/data/15108938/openapi.do

**심의유형이 개발단계·운영단계 모두 자동승인이라 신청 즉시 쓸 수 있다.** (무료)

1. 공공데이터포털 회원가입 → 로그인
2. 위 페이지 오른쪽 위 **[활용신청]** 클릭
3. 신청 양식
   - 활용목적: **웹 사이트 개발** 또는 **앱 개발** 선택
   - 상세 내용: 공모전 참가 + 서비스 설명을 두어 줄 (예: "직장인 신체 불균형 진단
     기반 공공 체육 강좌 추천 서비스 개발, 관광·체육 공공데이터 공모전 참가")
   - 라이선스 표시 동의에 체크
4. 신청 → **즉시 승인**
5. 마이페이지 → 오픈API → 개발계정 → 해당 API에서
   **일반 인증키(Decoding)** 를 복사

> **Encoding 키가 아니라 Decoding 키**를 써야 한다. Encoding 키를 넣으면
> 인증에 실패한다(`SERVICE_KEY_IS_NOT_REGISTERED_ERROR`).
> 승인 직후에는 키가 전파되는 데 몇 분에서 최대 1시간이 걸릴 수 있다.

**일일 트래픽은 개발계정 10,000건**이다. 한 번에 1,000건씩 받으므로 충분하다.

### 2. 인증키 등록

`local.properties` 에 한 줄 추가한다. 이 파일은 커밋되지 않는다.

```
DATA_GO_KR_KEY=발급받은인증키
```

### 3. 원자료 수집

```bash
python tools/fetch_kspo.py
```

파일 두 개가 만들어진다.

| 파일 | 내용 |
| --- | --- |
| `data/raw/kspo_measurements.csv` | 원본 그대로 (컬럼명이 `item_f0xx` 형태) |
| `data/raw/kspo_readable.csv` | **최서영에게 넘길 것.** 필요한 항목만 한글 열 이름으로 |

스크립트가 기대한 컬럼이 없으면 화면에 경고를 띄운다. 그런 경고가 뜨면
공단이 컬럼을 바꾼 것이니 매칭표를 다시 확인해야 한다.

### 4. 최서영에게 전달

`data/raw/kspo_readable.csv` 파일 하나만 넘기면 된다.
열 이름이 이미 한글이라 별도 설명이 필요 없다.

```
성별, 나이, 연령대, 신장_cm, 체중_kg, 상대악력_퍼센트,
교차윗몸일으키기_회, 앉아윗몸앞으로굽히기_cm, 왕복오래달리기_회,
제자리멀리뛰기_cm, 측정연월
```

---

## 최서영이 할 일 (파일을 받은 뒤)

1. 오입력 제외 기준을 정하고 적용 (`templates/오입력_제외기준.md`)
2. 성별 × 나이대(5세 단위) × 항목별로 백분위를 산출해
   `templates/체력기준표_템플릿.xlsx` 의 노란색 value 열을 채움
3. CSV UTF-8로 저장해 전달

기준표 템플릿에는 450줄의 조합이 이미 깔려 있으므로 **값만 채우면 된다.**
컬럼 매칭은 끝나 있으니 바로 2번부터 시작할 수 있다.

## 우리가 쓰는 측정 항목과 공단 원자료 매칭 (확인 완료)

API 명세를 확인해 컬럼 매칭을 **미리 끝냈다.** `fetch_kspo.py` 가 이 표대로
`kspo_readable.csv` 를 만들어 주므로, 최서영은 한글 열 이름 그대로 쓰면 된다.

| 우리 `item` | 항목 | 단위 | 원자료 컬럼 |
| --- | --- | --- | --- |
| `grip` | 상대악력 | % | `item_f028` (이미 상대값이라 계산 불필요) |
| `sit_up` | 교차윗몸일으키기 | 회 | `item_f019` |
| `sit_reach` | 앉아윗몸앞으로굽히기 | cm | `item_f012` |
| `shuttle_run` | 왕복오래달리기 | 회 | `item_f020` |
| `standing_jump` | 제자리멀리뛰기 | cm | `item_f022` |

성별·나이 구분에 쓰는 컬럼

| 용도 | 원자료 컬럼 |
| --- | --- |
| 성별 | `test_sex` |
| 나이 | `age_degree` |
| 연령대 | `age_class` |

> **성별 컬럼이 있는 것을 확인했다.** 앞서 걱정했던 "성별이 없으면 진단 로직을
> 바꿔야 한다"는 문제는 없다.
>
> 상대악력(`item_f028`)이 이미 계산된 값으로 제공되므로, 악력÷체중을 직접
> 계산할 필요가 없다. 좌·우 악력(`item_f007`, `item_f008`)은 따로 있다.

갱신이 필요하면:

## 강좌 데이터는 어떻게 하나 (2026-08-15 조사 완료)

후보 데이터셋을 전부 확인했다. **강좌 시간표를 전국 단위로 주는 공공데이터는 없다.**

| 후보 | 결론 | 이유 |
| --- | --- | --- |
| 스포츠강좌이용권 강좌정보 (문화데이터광장) | 못 씀 | 취약계층 유·청소년 대상. 시설명·주소·좌표·요일이 없다 |
| 공공체육시설 상세 정보 ([15107764](https://www.data.go.kr/data/15107764/openapi.do)) | **쓸 수 있음** (신청 필요) | 시설명·업종명·도로명주소·위경도가 다 있다 |
| 전국체육시설 정보 ([15113986](https://www.data.go.kr/data/15113986/openapi.do)) | 위와 동일 | 컬럼 구성이 같다 |
| 전국공공시설개방정보표준데이터 | 보조 | 시설 운영시간은 있으나 강좌 시간표는 없다 |

시설 데이터가 채워 주는 것과 아닌 것을 나누면 이렇게 된다.

| `courses.csv` 컬럼 | 출처 |
| --- | --- |
| `facility`, `lat`, `lng` | **공공체육시설 API** (`fetch_facilities.py`) |
| `sport` | 시설 API 의 `업종명` 에서 유도 |
| `title`, `weekday`, `start_time` | 시설 홈페이지 수동 수집 (최서영) |
| `tag_*` 5개 | 최서영 판단 (`templates/강좌태그표_템플릿.xlsx`) |

즉 **주소·좌표는 공공데이터로 채우고, 시간표만 손으로 채운다.** 수동 작업이
절반 이하로 줄고, 좌표 오타로 지도가 틀어질 일도 없어진다.

### 시설 데이터 받기 — 활용신청이 하나 더 필요했다

공공데이터포털은 **데이터셋마다 활용신청을 따로 받는다.** 국민체력100 키가 있어도
시설 API는 403이 났다. 15107764 와 15113986 에 활용신청을 하고 해결했다.
**인증키는 기존 것을 그대로 쓴다** (계정당 키는 하나다).

```bash
python tools/fetch_facilities.py    # 시설 원자료
python tools/build_courses.py       # 강좌표 시드 + 주소표
python tools/build_demo_courses.py  # 데모 강좌표 (실제 시설로)
```

> 겹쳐 붙은 경우도 있다(`(취약시설)(취약시설)○○체육센터`).

### 데모 강좌표에서 무엇이 실데이터인가

이전 데모는 시설명·좌표를 지어낸 것이었다. 26곳 중 20곳은 실재하지 않는 이름이라
지도에 엉뚱한 자리를 찍었다. 지금은 이렇게 나뉜다.

| 항목 | 출처 |
| --- | --- |
| 시설명·위도·경도·주소·종목 | **공공데이터** (15107764) |
| 강좌명·요일·시작시각 | **표본.** 최서영이 실제 시간표로 교체 |
| 체력요인 태그 | 종목에서 유도한 잠정값. 실제 강좌 확인 후 교체 |

조명이 없는 야외 종목(파크골프·국궁·양궁)은 평일 야간 강습이 성립하지 않아
주말 낮 시간대에만 배치한다.

## 데이터 수록 기간 (2026-08-15 확인)

`tools/fetch_kspo.py` 로 15만 건을 표본 수집해 확인한 결과, 이 데이터셋은
**2011-01 ~ 2026-07 전 기간**을 담고 있다. 최신 자료까지 있다.

| 연도 | 표본 건수 | | 연도 | 표본 건수 |
| --- | --- | --- | --- | --- |
| 2019 | 14,003 | | 2023 | 16,025 |
| 2020 | 6,003 | | 2024 | 16,032 |
| 2021 | 9,979 | | 2025 | 14,002 |
| 2022 | 12,994 | | 2026 | 4,001 |

> 페이지 끝을 확인할 때 `numOfRows` 를 작게 주면 마지막 페이지가 실제 끝이 아니다.
> 전체 건수 ÷ numOfRows 로 마지막 페이지를 계산해야 한다.
> (이 실수로 한때 "2012년에서 끝난다"고 잘못 판단했다.)

### 기준표는 2022년 이후 자료만 쓴다

공단이 2022년에 체력측정 인증기준을 개정했다. 그 이전 자료는 기준이 달라 섞으면 안 된다.
`tools/build_norms.py` 의 `SINCE_YM = "202201"` 이 이 필터다.

2022년 이후 표본만으로도 성별 × 9개 나이대 × 5개 항목 = 90칸이 모두
표본 100건 이상을 확보한다.
