# 스토어 배포 전 법적·보안 점검

2026-08-24. 코드·데이터·빌드 산출물을 직접 확인한 결과다. 추정이 아니라 실측이다.
법률 자문이 아니다. 판단이 필요한 항목은 그렇게 표시했다.

| | 건수 |

가장 큰 문제는 **개인정보처리방침이 없다**는 것이다. Play 스토어가 등록을 거부한다.

---

## 반드시 해결해야 하는 것

### 1. 개인정보처리방침이 없다 — 등록 불가

Google Play는 개인정보를 다루는 앱에 **처리방침 URL을 필수로 요구**한다.
지금 저장소에 방침 문서가 없다. 홈페이지에도 없다(`site/index.html` 에서
"개인정보"는 FAQ 한 줄뿐).

이 앱이 다루는 것은 아래와 같다. 방침에 이 목록이 그대로 들어가야 한다.

**서버로 보내는 것**

| 항목 | 어디에 |
| --- | --- |
| 성별, 나이 | 진단 |
| 키, 몸무게 | 진단 (BMI 계산) |
| 체력 측정값 5종 | 진단 |
| 직장·집 좌표(동 단위), 퇴근 시각 | 추천 |
| 기기 UUID | 전부 |

**서버가 실제로 저장하는 것** (`server/main.py` 확인)

- `diagnoses`: 기기 UUID, 측정 시각, 성별, 나이대, 약점 요인, 프로파일
- `match_fail_logs`: 기기 UUID, 시각, 약점 요인, **직장 좌표**, 퇴근 시각

키·몸무게·측정 원값은 **저장되지 않는다.** 계산에만 쓰고 버린다. 이건 좋은 설계이며
방침에 명시할 가치가 있다.

**기기에 저장하는 것** (`Prefs.kt`)
기기 UUID, 직장·집 좌표와 이름, 퇴근 시각, 최대 거리, 서버 주소, 온보딩/튜토리얼 완료 여부.

### 2. 건강정보 취급 — 동의 절차가 없다

개인정보보호법 제23조는 **건강에 관한 정보를 민감정보**로 본다. 체력 측정값과 BMI가
여기에 해당할 소지가 크다. 민감정보는 **다른 개인정보와 분리해 별도 동의**를 받아야 한다.

지금 앱은 온보딩에서 아무 동의도 받지 않는다.

> 판단 필요: 저장하지 않고 계산에만 쓰는 값도 '처리'에 해당하므로 동의 대상으로 보는 것이
> 안전하다. 최소한 첫 진단 화면에 "입력값은 또래 기준표와 대조하는 데만 쓰이며 저장되지
> 않습니다" 를 명시하고 동의를 받는 편이 낫다.

### 3. 진단 결과 접근에 소유자 확인이 없다

`server/main.py` 의 `/recommend` 와 `/facilities` 는 `diagnosis_id` 만으로 조회한다.

```
SELECT payload, profile FROM diagnoses WHERE diagnosis_id=?
```

요청한 기기(`device_id`)가 그 진단의 주인인지 확인하지 않는다.

게다가 id 가 짧다.

```
d_20260824_ + uuid4().hex[:8]     ← 무작위 부분이 32비트뿐
```

날짜는 추측 가능하므로 실질 탐색 공간이 42억이다. 속도 제한도 없어서 대입이 가능하다.
성공하면 남의 성별·나이대·약한 체력요인을 알 수 있다.

**고칠 것**: `uuid4().hex` 전체를 쓰고, 조회할 때 `device_id` 를 함께 확인한다.

### 4. 삭제 요청을 처리할 방법이 없다

개인정보보호법상 정보주체는 **삭제를 요구할 권리**가 있고, Play 스토어도
**계정·데이터 삭제 요청 경로**를 요구한다.

지금은 서버에 삭제 엔드포인트가 없고, 보존 기간도 정해져 있지 않다.

**고칠 것**: `DELETE /api/v1/me` 같은 엔드포인트(기기 UUID 기준)와,
앱 설정의 "내 기록 삭제" 버튼. 보존 기간도 방침에 적는다(예: 1년).

## 하는 편이 안전한 것

### 5. 오픈소스 라이선스 고지가 없다

앱이 쓰는 라이브러리는 전부 Apache 2.0 이고, **고지문 포함이 라이선스 조건**이다.

```
Jetpack Compose / AndroidX      Apache 2.0
Retrofit, OkHttp, Gson          Apache 2.0
Kakao Maps SDK                  카카오 이용약관
```

설정 화면에 "오픈소스 라이선스" 항목을 두면 된다.
`com.google.android.gms:play-services-oss-licenses` 를 쓰거나 텍스트 한 장이면 충분하다.

### 6. `android:allowBackup="true"`

기기의 앱 데이터가 구글 클라우드로 백업된다. 지금 저장하는 건 좌표와 설정뿐이라
심각하지 않지만, 건강 앱에서는 `false` 로 두는 편이 안전하다.

### 7. 설정의 "서버 주소" 입력란

사용자가 임의 주소를 넣으면 자기 신체 정보가 그리로 간다. 개발용 기능이다.
릴리스 빌드에서는 숨기거나 `BuildConfig.DEBUG` 로 가리는 것이 낫다.

평문 HTTP 는 이미 막혀 있다(`network_security_config.xml` 의 `base-config`).
릴리스에서는 HTTPS 만 통한다. 이 부분은 잘 돼 있다.

### 8. 서버에 접근 제한이 전혀 없다

CORS 설정도, 인증도, 속도 제한도 없다. 누구나 무제한으로 호출할 수 있다.
무료 호스팅이면 트래픽으로 죽을 수 있고, 3번의 대입 공격도 가능해진다.

최소한 IP 기준 속도 제한은 두는 것이 좋다.

### 9. 앱 이름 상표

`fitbalance` 는 흔한 조합이라 이미 등록된 상표가 있을 수 있다.
KIPRIS(kipris.or.kr)에서 "fitbalance", "핏밸런스" 를 검색해 보는 것이 안전하다.
스토어 등록 후 이의가 들어오면 이름을 바꿔야 한다.

## 확인 결과 문제 없는 것

### 공공데이터 이용 조건 — 상업적 이용 가능

세 데이터셋 모두 포털에서 직접 확인했다.

| 데이터 | 이용허락범위 | 비용 |
| --- | --- | --- |
| 국민체력100 체력인증센터 측정결과 (15108938) | **제한 없음** | 무료 |
| 공공체육시설 상세 정보 (15107764) | **제한 없음** | 무료 |
| 전국평생학습강좌표준데이터 (15013110) | **제한 없음** | 무료 |

"제한 없음" 은 상업적 이용과 변형을 포함한다. 스토어 배포에 걸림돌이 없다.
출처 표시는 의무는 아니지만 이미 하고 있다(홈페이지 푸터, 앱 스플래시).

> 다만 홈페이지 푸터의 출처 목록에 **강좌 데이터가 빠져 있다.**
> "출처 · 전국평생학습강좌표준데이터(교육부·지방자치단체)" 를 추가하는 것이 맞다.

### 인증키가 앱에 새지 않는다

빌드된 APK 를 열어 `local.properties` 의 실제 값과 대조했다.

```
KAKAO_MAP_KEY      APK에 포함: True    ← 정상. 네이티브 앱 키는 원래 앱에 들어가며
                                        키 해시로 보호된다
DATA_GO_KR_KEY     APK에 포함: False   ← 서버 전용. 정상
KAKAO_REST_KEY     APK에 포함: False   ← 서버 전용. 정상
```

### git 이력이 깨끗하다

저장소 전체 이력에서 각 인증키 값을 검색했다. **한 건도 나오지 않았다.**
`local.properties` 는 커밋된 적이 없다.

### 릴리스 로그에 개인정보가 안 찍힌다

`Api.kt` 가 `BuildConfig.DEBUG` 로 갈라 릴리스에서는 `Level.NONE` 이다.
디버그에서도 `BASIC` 이라 본문은 안 찍힌다.

### 위치 권한을 안 쓴다

`AndroidManifest.xml` 의 권한은 `INTERNET` 하나뿐이다. GPS 를 읽지 않고,
사용자가 목록에서 고른 동의 중심 좌표만 쓴다. 위치정보법상 개인위치정보
수집으로 보기 어렵다.

### 폰트 라이선스가 들어 있다

`site/fonts/LICENSE-Pretendard.txt` 포함. Pretendard 는 OFL 이며 웹폰트
재배포가 허용된다.

### 마스코트·아이콘이 직접 만든 것

Compose Canvas 로 그린 도형이다. 외부 이미지를 쓰지 않았다.

## 의료기기로 오해될 소지

체력 측정과 등급 표시는 **의료기기법상 의료기기가 아니다.** 질병 진단·치료를
표방하지 않기 때문이다. 다만 앱 곳곳에 "진단" 이라는 말이 34곳 쓰인다.

`처방` 이 쓰인 4곳은 모두 **국민체력100 센터가 제공하는 운동처방을 설명하는
문맥**이라 앱이 처방한다고 하지 않는다. 문제 없다.

안전하게 하려면 결과 화면에 한 줄 넣는다.

> 이 결과는 국민체력100 공개 기준표와 대조한 참고용 정보이며 의학적 진단이 아닙니다.
